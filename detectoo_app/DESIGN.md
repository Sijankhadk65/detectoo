# DESIGN.md

Design guidelines for the Detectoo app — a plant care utility app.

## Typography

Text is categorized into four levels, using a mix of Serif and Sans-Serif fonts:

| Category     | Usage                              |
| ------------ | ---------------------------------- |
| Title        | Screen titles, hero text           |
| Heading      | Section headers                    |
| Sub-Heading  | Subsection headers, card titles    |
| Description  | Body text, labels, captions        |

- **Serif** fonts for Title and Heading to give a natural, organic feel
- **Sans-Serif** fonts for Sub-Heading and Description for readability

## Color

Green monotone palette — all UI elements derive from shades of green to reflect the plant care theme.

- Use varying shades, tints, and tones of green for backgrounds, surfaces, text, and accents
- Maintain sufficient contrast between foreground and background for accessibility
- Avoid introducing other hue families; keep the palette strictly monotone green

## Theme

- Light theme only (for now)

## Component Style

- **Corners**: Rounded corners on all interactive and container elements
- **Elevation**: Minimal — use subtle shadows sparingly, prefer flat or slightly raised surfaces
- **Spacing**: Generous padding and margins for a clean, breathable layout

## General Look & Feel

- **Modern and playful** — friendly, approachable UI that feels light and fun
- Lean into the plant/nature theme through color and subtle organic shapes
- Keep interfaces uncluttered with clear visual hierarchy
